## Security review

Session fixation protection, HTTP-only SameSite=Lax cookies, session-bound CSRF, enabled-user checks, active membership, scoped service permissions/composite tenant FKs and generic error responses remain enforced. Real HTTP tests cover cross-tenant IDs, VIEWER writes, CSRF, disabled/revoked sessions, foreign/inactive recipients and preview replay. CORS is not enabled in the application security chain; deploy same origin. Production secure cookies default false unless explicitly configured: enforce SESSION_COOKIE_SECURE=true and block direct public backend access.

No committed .env secrets were found in tracked environment files; only frontend examples are tracked. High-confidence AWS access-key/private-key/OpenAI-key patterns were also scanned across all locally fetched Git histories with zero matches; this is a limited pattern scan, not a certification that no secret exists. API proxy candidate preserves backend status/errors. Login brute-force throttling was absent in backend source; candidate proxy supplies an initial limiter, but untested/undeployed configuration does not resolve exposure. No public release before staged abuse-control verification.

AI has durable budgets/rate limits, bounded read tools, fresh authorization, validated sources and no executable model tools. Prompt injection cannot grant a write tool, but actual model factuality/injection resistance remains unverified. Context/private consent and deletion tests pass with mocked inference. Conversation expiry is 20 minutes plus cleanup grace; previews five minutes. Provider copies, backups, legal retention and deletion process remain policy gaps.

Compatible patch overrides target Jackson BOM 2.21.7, Tomcat 10.1.60, PostgreSQL JDBC 42.7.14 and Log4j 2.25.5. Proposed versions returned zero OSV matches. Actual hardened artifact passed clean verify (395 passed, 18 skipped) and all 17 real HTTP scenarios (one bridge skipped). Resolved 97-dependency rescan retains only two Spring matches; 16 matches were removed. Spring 6.2.19 advisories [CVE-2026-47890](https://spring.io/security/cve-2026-47890/) and [CVE-2026-47884](https://spring.io/security/cve-2026-47884/) are rated LOW/MEDIUM by the vendor despite CRITICAL registry classifications. Source search found no SSE fragment rendering, XsltView/ViewResolver or dynamic view mapping; applicability is not established in this REST-only source. The compatible 6.2.20 fix is enterprise-only; a future supported framework migration or enterprise patch needs review. Keep these matches visible; do not silently suppress them or claim zero backend vulnerabilities.
